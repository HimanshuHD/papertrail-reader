# PaperTrail v2.2.0 — Multiple-document workspace

Status: release candidate; not yet released. Previous stable version: v2.1.1.

## Changes

- Open PDFs and EPUBs in accessible document tabs with independent positions, reader settings, annotations and utility state. Restore saved tab shells and reconnect local sources after reload.
- Switch between retained readers without reopening their engines. Hidden readers expire after five inactive minutes; closing releases the session. Visible Split view readers remain mounted.
- Use a compact tab/header layout, collapsible library, responsive library actions, smaller utility fields, reusable file icons and click-operated build-details popover.
- Read two different open documents in **Split view**, including mixed PDF/EPUB pairs. Focus either pane, swap their order or return to one reader. Below 960px of available reader width, explicit Show controls switch the visible document. Selecting a third tab replaces the focused slot.
- Export committed highlights and notes from the current PDF/EPUB as portable versioned JSON. Export is disabled when there are no saved annotations; filtering does not omit saved entries from export.
- Run Visual QA explicitly when wanted, independently of functional CI, preview and delivery workflows. Manual execution does not approve or overwrite baselines.

## Boundaries

Split view is independent reading, not an automated comparison: no text/data diffing, linked scrolling or synchronized annotations. This increment supports two visible documents, not configurable multi-pane layouts. Split arrangements are transient across reload; ordinary per-document saved state remains.

PDF has two-page viewing. EPUB uses scrolling chapters without two-page mode. Annotation export has no importer. File access still depends on browser capabilities and permissions; document bytes are not persisted as workspace metadata. Diagnostics #167 and broader process-memory/performance acceptance #16 remain separate.
