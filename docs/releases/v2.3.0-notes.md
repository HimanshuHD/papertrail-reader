# PaperTrail v2.3.0 — Reader improvements, diagnostics and reliability

PaperTrail v2.3.0 brings updates to PDF and EPUB reading, better handling of
large documents and opt-in developer diagnostics. It is the final
increment of [Roadmap 3](https://github.com/HimanshuHD/papertrail-reader/wiki/Roadmap-3).

The release inventory compares the published `v2.2.0` tree directly with the
accepted staging candidate. Release publication and the fixture-scope decision
are tracked in the [release record](https://github.com/HimanshuHD/papertrail-reader/blob/v2.3.0/docs/releases/v2.3.0.md).

## Reading and accessibility

- Open underlined PDF and EPUB links. Internal links navigate within the
  document, and external links ask for confirmation before opening a new tab.
  Escape and Cancel restore focus to the source link; keyboard and middle-click
  use the same confirmation. EPUB link handling works in WebKit while document
  scripts, inline handlers and unsolicited remote resources remain blocked. [#291](https://github.com/HimanshuHD/papertrail-reader/issues/291)
- Compact rendering notices leave more space for the page. Scrollbar clearance,
  dark-mode illustration backing and a dedicated diagnostics entry improve
  the reading layout. [#289](https://github.com/HimanshuHD/papertrail-reader/issues/289)
- Formatted EPUBs preserve more authored headings, SVG illustrations and
  supported embedded fonts. Oversized or unsupported resources fall back to
  readable content with a notice. Large books use a bounded chapter cache.
  [#280](https://github.com/HimanshuHD/papertrail-reader/issues/280), [#282](https://github.com/HimanshuHD/papertrail-reader/issues/282), [#284](https://github.com/HimanshuHD/papertrail-reader/issues/284), [#286](https://github.com/HimanshuHD/papertrail-reader/issues/286)
- EPUBs restore their selected reading mode and keep the visible text anchor
  through layout or mode changes. Chapter spacing respects the reader viewport.
  [#276](https://github.com/HimanshuHD/papertrail-reader/issues/276), [#279](https://github.com/HimanshuHD/papertrail-reader/issues/279)

- Library actions remain selectable with the mouse when focus would otherwise
  dismiss the menu. Controlled picker cancellation, denial and unavailable access
  preserve the active reader and exercise fallback recovery.
  [#269](https://github.com/HimanshuHD/papertrail-reader/pull/269)

## Large documents and reader lifecycle

- Large PDFs mount full page components around the reading position. Distant
  placeholders preserve layout for scrolling and jumps. Responsive spreads,
  zoom and horizontal panning of oversized pages have regression coverage.
  [#296](https://github.com/HimanshuHD/papertrail-reader/issues/296), [#304](https://github.com/HimanshuHD/papertrail-reader/issues/304)
- EPUBs coalesce scroll-time position capture and reuse note geometry. Explicit
  close releases engine listeners and workspace observer ownership. EPUB
  preparation avoids repeated parsing and moves large archive packing off the
  main thread while keeping cancellation and validation. Long chapters avoid
  repeated highlight indexing, and PDF search reuses page text while keeping
  matches and saved selectors intact. [#295](https://github.com/HimanshuHD/papertrail-reader/issues/295), [#297](https://github.com/HimanshuHD/papertrail-reader/issues/297), [#300](https://github.com/HimanshuHD/papertrail-reader/issues/300), [#304](https://github.com/HimanshuHD/papertrail-reader/issues/304)
- PDF rendering limits concurrent pending page pipelines. PDF and EPUB highlights
  use frame-coalesced hover work and compact text mappings that preserve saved
  selectors. [#298](https://github.com/HimanshuHD/papertrail-reader/issues/298), [#299](https://github.com/HimanshuHD/papertrail-reader/issues/299), [#301](https://github.com/HimanshuHD/papertrail-reader/issues/301)

## Developer diagnostics and delivery

- Diagnostics-enabled builds offer a local dashboard for operation timing,
  responsiveness, resources, reader lifecycle and JSON export. Production
  builds keep instrumentation off by default. [#167](https://github.com/HimanshuHD/papertrail-reader/issues/167), [#249](https://github.com/HimanshuHD/papertrail-reader/issues/249), [#250](https://github.com/HimanshuHD/papertrail-reader/issues/250), [#251](https://github.com/HimanshuHD/papertrail-reader/issues/251), [#252](https://github.com/HimanshuHD/papertrail-reader/issues/252), [#253](https://github.com/HimanshuHD/papertrail-reader/issues/253)
- Scoped QA fixtures exercise operation targets for directory scanning and
  PDF/EPUB opening. The evidence distinguishes temporary page allocation,
  retained heap and process observations. The targets apply to their documented
  fixtures and configuration and are validated in the opt-in test harness;
  normal application indicators do not inherit these targets. [#16](https://github.com/HimanshuHD/papertrail-reader/issues/16)
- Browser acceptance and delivery checks cover reader recovery and focus,
  EPUB sandbox behavior and browser job startup. Visual QA stays independently
  dispatched and manual-only. The three real five-minute inactivity tests
  run concurrently across engines; the remaining reader checks stay serial.
  The full 123-case reader run passed on the #293 source; #294 subsequently
  updated only the staging browser sanitizer test.
  [#293](https://github.com/HimanshuHD/papertrail-reader/pull/293), [#262](https://github.com/HimanshuHD/papertrail-reader/pull/262), [#263](https://github.com/HimanshuHD/papertrail-reader/pull/263), [#264](https://github.com/HimanshuHD/papertrail-reader/pull/264), [#265](https://github.com/HimanshuHD/papertrail-reader/pull/265), [#268](https://github.com/HimanshuHD/papertrail-reader/pull/268), [#269](https://github.com/HimanshuHD/papertrail-reader/pull/269), [#294](https://github.com/HimanshuHD/papertrail-reader/pull/294)

## Roadmap 3 release history

Startup loading shipped in [v2.1.0](https://github.com/HimanshuHD/papertrail-reader/releases/tag/v2.1.0), versioned delivery in [v2.1.1](https://github.com/HimanshuHD/papertrail-reader/releases/tag/v2.1.1)
and the multiple-document workspace in [v2.2.0](https://github.com/HimanshuHD/papertrail-reader/releases/tag/v2.2.0). This release builds on
those increments with reader refinements, diagnostics and performance work.

Native-folder permission validation, actual screen-reader validation and EPUB
full-book search remain separate follow-ups ([#274](https://github.com/HimanshuHD/papertrail-reader/issues/274),
[#275](https://github.com/HimanshuHD/papertrail-reader/issues/275),
[#278](https://github.com/HimanshuHD/papertrail-reader/issues/278)).
