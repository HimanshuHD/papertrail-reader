## Release blockers found after #243

Staging integration failed twice on each affected case: Chromium 320 tab-overflow menu bounds and WebKit 1440 EPUB frame click ownership. #240/#18 remain open; #243 merge does not establish accepted staging delivery. The release candidate constrains the overflow menu to its tab-bar containing block and detects focus entering its sandboxed EPUB iframe from the trusted parent alongside existing frame listeners, without enabling scripts in document content. The wide WebKit regression now passes locally after reproducing the original failure; local tests use extracted runtime dependencies outside the repository. Fresh production-path browser validation is required; these fixes must be synchronized back to staging.
