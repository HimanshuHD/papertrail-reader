Status: release candidate; production deployment and tag are pending.

## Changes

- Early, responsive startup screen with the supplied book-flip sprite, progress milestones, reduced-motion support and retry feedback.
- Production and staging report completed application startup phases without an artificial minimum delay. Numbered preview builds retain the seven-second animation review hold; progress is not a network-byte percentage.
- Saved-library metadata is restored before permission renewal/document reopening, keeping startup separate from live file access.
- Deployment workflow refinements for current-candidate validation, scoped CI events, visual evidence and verified docs-only staging promotion. Strict artifact identities/checksums, channel preservation and stale-publication checks remain enforced.
- Browser fixtures wait for startup readiness before inspecting sidebar state or reselecting PDF/EPUB files after reload.
