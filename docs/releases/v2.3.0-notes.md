# PaperTrail v2.3.0 — Reader performance and reliability

Release notes draft for the final Roadmap 3 increment. The proposed version is
v2.3.0. Use the release checklist to record the exact accepted source and live
delivery before publishing these notes.

## Reading improvements

- Large PDFs mount full page components around the reading position. Distant
  placeholders preserve layout for scrolling and jumps, including mixed page
  sizes, zoom and two-page mode.
- PDF placeholder geometry is reused between changes that affect it. In the
  generated 1,001-page scroll comparison, median sampled temporary page-target
  JavaScript allocation fell from 25.00 MiB to 4.09 MiB. The same comparison
  retained the document height, scroll distance and mounted page count.
- EPUB reading coalesces position reporting and reduces repeated location and
  highlight work. Explicit close cleans up engine listeners and cancels pending
  reader work.
- PDF and EPUB performance changes have functional coverage for saved positions,
  highlights, selection, search, zoom, spreads, warm tabs and split view.

## Developer diagnostics

Diagnostics-enabled builds expose local timing, sensor and resource evidence.
The external profiler separates active workload time from checkpoint collection.
Versioned fixture targets can be reviewed using the diagnostic export from the
matching Chromium QA run. The review covers a 1,000-file directory scan, a
1,001-page PDF cold open and a long EPUB cold open.

The measurement reports distinguish temporary allocations, retained page heap,
browser process RSS and measured Linux process CPU. Page-target samples exclude
separate workers and native allocations. Physical GPU utilization and memory
are unavailable in the software-graphics measurement setup. The performance
references apply to their documented generated fixtures and browser scope.
