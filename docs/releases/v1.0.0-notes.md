# PaperTrail v1.0.0

The first major release of PaperTrail brings a quiet, local-first PDF reading workspace to your browser.

## Read local PDFs

Choose files or a folder, browse a clean library and read without uploading your document bytes. The library can be resized or hidden, with independent scrolling for documents and reading panes.

Continuous pages, selectable text, page navigation, zoom, fit width/page, contents, fullscreen and keyboard help keep reading controls close at hand. Light and dark themes persist between visits.

## Find the exact passage

Search result snippets wrap safely and highlight the matched term, with up to 50 characters of context on each side. Clicking a result brings its exact occurrence into view and highlights it in the PDF.

## A smoother reader

This release fixes rendering flashes, reading-position changes during zoom/fit and page-number/navigation drift after scrollbar jumps. Large PDFs open without rendering every page first; previews are reused within a bounded cache. Loading feedback, accessible icon controls, panel transitions, title labels and the version footer are polished across narrow and desktop layouts.

## Release scope

This release focuses on PDF reading. Scanned PDFs have no OCR search, and password-entry UI is not included. EPUB, saved reading positions/bookmarks, annotations, tabs and a desktop application are planned for later releases.

Regression validation covers Playwright Chromium at five viewport widths, both themes and a synthetic 1,001-page document, plus owner-confirmed affected-PDF checks on Windows Chrome. Broader browser/device certification remains future work. Folder picking depends on browser support and permissions; file/folder input fallbacks remain available.
